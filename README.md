# Lab 4: Interactive Logic

## After Class Compass

This interactive webpage creates a personalized study plan from three user
inputs: energy level, available time, and the next deadline.

The JavaScript includes:

- Variables for the form elements and application state
- An object that stores four possible outcomes
- An `if / else if / else` conditional function
- A form event listener
- DOM manipulation that changes the title, message, steps, colour, and state
- Previous-plan and plan-count state

Possible outcomes:

1. Reset Break
2. Priority Sprint
3. Deep Focus Session
4. Quick Review
